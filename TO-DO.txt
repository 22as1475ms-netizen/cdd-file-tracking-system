Priority split

Must finish before demo

- Confirm the current notification feed correctly shows routed file share and route completion events
- Verify the dashboard and routed workspace views show active and completed routes correctly
- Run and fix the focused workflow tests needed to support the demo story
- Decide whether clarification comments are part of the demo; if yes, implement them before demo

Must finish before production
- Account created under your section notification
- Section assignment changed notification
- Stronger route/status centralization to reduce workflow drift and typo bugs
- Stronger permission/workflow policy centralization so role rules stay consistent
- Admin workspace performance hardening for larger user/document counts
- Cleaner migration structure for safer upgrades and deployment predictability
- Storage upgrade if the expected production load makes local/database-backed storage risky
- Dead-code cleanup phase 2 for abandoned organization-management leftovers if not part of final scope

Can wait

- Routed-file clarification comments if the workflow can proceed without in-app discussion
